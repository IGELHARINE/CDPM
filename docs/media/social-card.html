CDPM

An MCP server that gives Claude Code agents real Chrome windows, addressed by slot number.

  • Two sessions can drive one Chrome, a tab each
  • Input via CDP Input.*, no webdriver flag
  • Profiles persist across reboots and Chrome updates
Each slot gets its own numbered taskbar button on Windows and macOS
